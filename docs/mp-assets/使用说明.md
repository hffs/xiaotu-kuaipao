# 小兔快跑 · 小程序 / 小游戏上架图片

这些图是按微信公众平台常见要求准备的，可直接上传。角色外形和配色都跟游戏里的兔兔一致。

## 图标（头像）

- `图标-512.png`：512×512，建议优先上传这一张。
- `图标-1080.png`：更大的原图，后台如果接受也可以用。
- `图标-144.png`：平台有时写建议 144×144，备用。

上传位置：微信公众平台 → 小程序信息 → 头像 / 图标。请用 PNG。图标不要再加字，小尺寸下会看不清。

## 分享图（5:4）

- `分享图-1000x800.png`：建议上传这一张。
- `分享图-500x400.png`：官方示例常用尺寸，备用。

上传位置：公众平台 → 游戏能力地图 / 运营素材管理 → 分享图片。审核通过后，再把图片编号和地址填进分享接口。

微信分享卡片里，图片的最佳显示比例是 5:4。转发标题可以另外写，例如：「答对一题，兔兔就向前跑一步」。
