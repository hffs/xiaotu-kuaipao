# 小兔快跑

给 6–8 岁孩子的微信小游戏。答对题目，兔兔就在跑道上向前跑；古诗词则是走进《静夜思》里看一看。

界面是中文，竖屏，四个大按钮。孩子只需要点，不用打字。

## 浏览器预览

在项目根目录启动静态服务：

```bash
python3 -m http.server 8647
```

然后打开 [http://127.0.0.1:8647/preview/](http://127.0.0.1:8647/preview/)。

预览用的是和微信小游戏同一套 `js/` 代码。`preview/wx-mock.js` 把 `wx.createCanvas`、触摸、本地存储、分享和剪贴板补成浏览器能用的版本。进度存在这台电脑的 `localStorage`（键名 `xiaotu-kuaipao-v1`）。

键盘 `1` 到 `4` 对应四个答案，方便在电脑上试玩。

## 用微信开发者工具打开

1. 安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。
2. 选择「小游戏」，导入本仓库根目录（里面有 `game.json` 和 `project.config.json`）。
3. 编译类型已经是 `game`，入口是 `game.js`。
4. 详情里的调试基础库建议使用 `3.6` 或更新版本。

`project.config.json` 里的 AppId 是占位符 `wx0000000000000000`。换成你自己的：

1. 打开 [微信公众平台](https://mp.weixin.qq.com/) 的小游戏账号，复制 AppId。
2. 把 `project.config.json` 的 `"appid"` 改成那一串。
3. 重新用开发者工具导入。没有正式 AppId 时，也可以在工具里用测试号先看效果。

## 这一版有什么

- 首页可选数学、语文、英语、古诗词。
- 数学、语文、英语各有 6 关，全部免费。一关 10 题，没有倒计时。
- 答对：兔兔向前跑一段。10 题都对就到终点。
- 3 颗心。答错会轻轻晃一下，提示「再试一次」，兔兔停在原地，并换一道同类型的新题，不会往回跑。
- 心用完就结束这一关，可以再玩一次。
- 永远是四个大选项。
- 数学：加法、进退位、数一数、比多少，还有一步应用题。
- 语文：看图选字、组词、看拼音选字、补全短句、看提示选字。
- 英语：动物、颜色、小物、动作、天气和校园词。
- 古诗词有三篇，都能走进去：《静夜思》《春晓》《登鹳雀楼》。每篇大约四个停靠点，补全诗句。可以点「听一听」播放一段简单音阶，不是朗诵。
- 这一版不收费。只有还没写题目的关卡才会显示「即将更新」。
- 好友进度、分享卡片、同一道题的挑战都有界面，预览里用示例好友。

题目、关卡和诗的场景都在 `js/data/` 里。以后加内容，改这些文件再发一版即可，没有后台。

## 还没接上的部分

- **收费**：第一版没有价格、没有解锁，也没有微信支付。以后如果要收费，再单独加一版。
- **微信分享**：按钮会调用 `wx.shareAppMessage`。浏览器预览里会打开一张分享卡片，可以复制文案，或模拟发到「家庭群」「一年级小队」。真正发到群里，还需要在小游戏后台配置分享图。
- **好友数据**：预览和这一版都用 `js/data/meta.js` 里的示例好友。没有实时对战、聊天和公开排行榜。
- **更多关卡**：三科各 6 关、古诗三篇都已经能玩。以后再加关卡时，没有题库的才会显示「即将更新」。

没有广告。

## 目录

```
game.js                 微信小游戏入口
game.json               竖屏等配置
project.config.json     开发者工具项目，含占位 AppId
js/core.js              画布、触摸、存档、音效和分享
js/draw.js              兔兔和场景
js/icons.js             看图题用的简笔画
js/data/                关卡、题库、《静夜思》、示例好友
js/screens/             各个界面
preview/                浏览器预览
docs/screenshots/       界面截图
```

## 加一道题

打开对应的 `js/data/math.js`、`chinese.js` 或 `english.js`，往题库数组里追加一题。每题四个选项，`answer` 必须是其中之一，并写上 `type`。答错时会再发一道相同 `type` 的题。

看图题的 `visual.kind` 可以是 `icon`（名字要在 `js/icons.js` 里）、`char`（大字组词）、`color` 或 `dots`（数学圆点）。

## 进度存在哪里

`wx.setStorageSync` / 浏览器 `localStorage`，键名 `xiaotu-kuaipao-v1`。记下每关最高星数，以及古诗词是否学完。好友页底部可以清除本机进度。
